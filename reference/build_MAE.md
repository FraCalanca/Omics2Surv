# Build a MultiAssayExperiment Object from SummarizedExperiment Objects

Constructs a `MultiAssayExperiment` (MAE) container integrating multiple
omics `SummarizedExperiment` objects with associated clinical data.
Supports the case where different omics assays cover different subsets
of samples, as is typical after per-omic train/test splitting and
preprocessing.

## Usage

``` r
build_MAE(omics_list, clinical_data)
```

## Arguments

- omics_list:

  Named list of `SummarizedExperiment` objects, one per omics layer
  (e.g.
  `list(mRNA = se_rna, miRNA = se_mirna, CNV = se_cnv, methylation = se_meth)`).
  List names become experiment identifiers in the MAE. Column names of
  each SE must be set to sample identifiers.

- clinical_data:

  Matrix or data frame of clinical data with **variables as rows** and
  **samples as columns** (the same orientation used by the `prepare_*`
  functions). Must contain at least the union of all sample identifiers
  present across `omics_list`. Rows `"overall_survival"` and `"status"`
  are expected for survival analysis.

## Value

A `MultiAssayExperiment` object with:

- `experiments`: The assays from `omics_list`.

- `colData`: Clinical data as a `DataFrame` (samples as rows, variables
  as columns).

- `sampleMap`: Auto-generated by `MultiAssayExperiment`, mapping each
  assay column to its `colData` row.

## Details

**Common sample assumption:** multi-omics survival analysis requires the
same patients across all layers. When `omics_list` contains more than
one element, `build_MAE` automatically restricts all assays to their
common sample set (intersection). A message reports how many samples are
dropped per assay. If the intersection is empty the function stops with
an error.
